description: 매 대화 종료 시 작업내역/ 폴더에 텍스트 파일 자동 저장 (별도 요청 불필요)
type: feedback
---

대화 종료 시 `작업내역/작업내역_YYYYMMDD.txt` 파일을 항상 자동 저장할 것.

**Why:** 사용자가 매번 요청하지 않아도 작업 기록이 남아야 함. 하루에 여러 번 작업할 수 있으므로 시간 범위도 포함.

**How to apply:**
- 경로: `작업내역/작업내역_YYYYMMDD.txt` (같은 날 여러 번이면 `_2`, `_3` 등 붙이기)
- 내용: 날짜 + 시간 범위, 작업 항목별 문제/수정/결과, 수정된 파일 목록
- memory 세션 기록과 별개로 항상 저장
