## 2026-03-23 세션 요약

### 작업 내용
1. **코드 감지 후 모니터링 재시작 방지**:
   - `_code_detected_this_slot` 플래그 추가
   - 코드 감지 후 스케줄러가 모니터링 재시작 안 함
   - 스케줄 범위 밖으로 나가면 플래그 리셋 (다음 타임 정상 시작)

2. **수동 정지 시 재시작 방지**:
   - `_stop_monitor(manual=True)` — 버튼/대시보드에서 정지 시 스케줄러 재시작 방지

3. **대시보드 외부 start_monitor 명령 차단**:
   - 코드 감지된 슬롯에서 대시보드 start_monitor 명령도 무시
   - "코드 감지 슬롯 — 외부 start_monitor 무시" 로그 추가

4. **대시보드 비밀번호 2개 설정**:
   - Railway 변수명 `ADMIN_1_PASSWORD` → `ADMIN_PASSWORD_2`로 수정 (코드와 일치)
   - 디버그 로그 추가로 로그인 문제 원인 파악
   - 두 비밀번호 모두 정상 작동 확인

5. **로그 분석**:
   - 07:30 스케줄: 자동 시작 ✓, 코드 감지 ✓, 08:10 자동 종료 ✓
   - 23:30 스케줄: stop=00:00 자정 넘김 버그 → 이전 커밋에서 수정 완료
   - 코드 감지 후 대시보드 start_monitor로 재시작되는 문제 발견 → 수정

6. **Selenium 빌드 진입점 수정**:
   - app.py → main.py로 빌드 (app.py 빌드 시 검은 창)
