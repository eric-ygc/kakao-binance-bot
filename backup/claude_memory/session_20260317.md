### 버그 수정 (세션 2)

#### 1. 코드 제출 "Frequent requests" 재시도 로직 추가
- **문제**: `_api_submit_code`에 재시도 없음 → 즉시 다른 사이트로 전환 (같은 API 서버라 무의미)
- **수정**: 같은 토큰으로 최대 6회 재시도, 점진적 대기 (3→6→9→12→15초)
- 상수: `CODE_RETRY_COUNT=6`, `CODE_RETRY_WAIT=3`

#### 2. 스케줄러 범위 기반 시작
- **문제**: 정확한 시작 시각(07:30)에만 시작 시도 → 이미 실행 중이면 스킵, 이후 재시작 불가
- **수정**: `start_t <= now < stop_t` 범위 체크로 변경
- 자동 입력 중에는 대기 (`not self._auto_input_active` 조건 추가)
- 자동 입력 완료 후 범위 안이면 모니터링 자동 재시작
