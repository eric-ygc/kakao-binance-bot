---
name: 파일명/폴더명 영문 사용
description: 파일명, 폴더명을 한글로 만들려고 하면 영문으로 만들라고 알려줄 것
type: feedback
---

파일명이든 폴더명이든 한글로 만들려고 하면 영문으로 만들라고 얘기해줄 것.

**Why:** GitHub Release 에셋 한글 파일명이 URL 인코딩되면서 404 에러 반복 발생. 한글 경로는 빌드, 배포, 인코딩 문제의 원인이 됨.

**How to apply:** 사용자가 한글 파일명/폴더명을 제안하면 영문 대안을 제시하고 이유 설명. 기존 한글 파일명은 그대로 두되, 새로 만들 때는 영문 사용 권장.
