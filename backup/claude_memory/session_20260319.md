### 핵심 수정 패턴
```python
# 변경 전: 예외 시 after() 안 불려서 루프 죽음
def _poll_queue(self):
    try: ...
    except queue.Empty: pass
    self._check_monitor_schedule()
    self.after(200, self._poll_queue)

# 변경 후: finally로 after() 보장
def _poll_queue(self):
    try:
        try: ...
        except queue.Empty: pass
        self._check_monitor_schedule()
    except Exception as e:
        logger.error(f"_poll_queue 오류: {e}")
    finally:
        self.after(200, self._poll_queue)
```

**Why:** 이전 수정(2a5c964)은 스케줄러 로직 문제였고, 이번은 폴링 루프 자체가 죽는 구조적 문제
**How to apply:** 향후 after() 체인 패턴 사용 시 반드시 try/finally로 감싸기
