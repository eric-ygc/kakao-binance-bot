# 작업내역 2026-04-28

## 1. 대시보드 일괄 작업 기능 추가

### 전체 PC 모니터링 정지 버튼
- 코드 전체전송 버튼 옆에 **"⏸ 전체 정지"** 버튼 추가
- 클릭 시 확인 팝업 → 온라인 PC 전체에 `stop_monitor` 명령 전송
- 각 PC 들어가서 정지 누르는 수고 제거

### 사이트 URL 일괄 적용 섹션
- 대시보드 메인에 사이트 URL 10개 입력란 추가
- "전체 PC에 적용" 버튼 한 번으로 모든 PC의 사이트 URL 동기화
- 기존: 각 PC마다 들어가서 입력 → 개선: 한 번에 적용
- operator 계정에는 표시 안 됨 (admin만 사용 가능)

## 2. URL 입력값 사라지는 버그 수정
- 페이지 SSE 자동 갱신 시 사이트 URL 입력값이 사라지는 문제
- 입력값 보존 로직 추가 (renderOverview 호출 시 prev 값 저장 → 복원)

## 3. URL 입력값 localStorage 저장
- 대시보드 재시작 후에도 사이트 URL이 유지되도록 localStorage 저장
- 입력 시 자동 저장 (oninput 이벤트)
- 페이지 로드 시 localStorage에서 자동 복원

## 4. 보너스픽 처리량 확인
- Selenium 우선, 워커 2개, 10초 간격
- 계정당 30~60초 처리
- 10분 동안 약 20~30계정 처리 가능

## 5. 메시지 로그 개선 논의 (다음 작업)

1. **어느 단계에서 실패했는지 구분 저장**
   - 로그인 실패 / 클릭 실패 / 코드 입력 실패 등
2. **에러 종류 분류**
   - Login 실패, 코드 무효 (Invalid parameter), 사이트 차단 (429), 네트워크 오류 등
3. **별도 로그 파일에 누적 저장**
   - 날짜별 파일로 저장
4. **대시보드 표시**
