## 3. PC_01 버전 다운그레이드 문제 해결
### 원인 파악
- PC_01에 **두 개의 exe 파일**이 공존
  - `픽보조_Selenium.exe` = S.1.0.7 (구버전, 자동 실행됨)
  - `PicAssist_Selenium.exe` = S.1.0.8 (신버전, 배포 시 생성)
- 이전 배포에서 exe_name 필드에 영문명(`PicAssist_Selenium.exe`) 사용한 이력 때문
- PC 재시작 시 구버전 `픽보조_Selenium.exe`가 자동 실행되어 다운그레이드처럼 보임

### 해결
- 각 PC 원격 접속 후:
  1. 두 프로세스 종료
  2. 구버전 `픽보조_Selenium.exe` 삭제
  3. `PicAssist_Selenium.exe` → `픽보조_Selenium.exe`로 이름 변경
  4. 재실행
- 전체 PC 정리 완료

### 교훈
- **대시보드 배포 시 exe 파일명은 항상 `픽보조_Selenium.exe` (한글)** 사용
- 영문명 사용 시 중복 파일 생성 위험
